# 🐍 Freaker126 Neon Snake

A single-file retro neon arcade Snake game built with pure HTML5, CSS3, and JavaScript! Designed to play seamlessly across desktop and mobile browsers with zero external assets or downloads.

### 🎮 How to Play & Controls
* **Mobile Phone / Tablet:** **Swipe** anywhere on the screen in the direction you want the snake to turn (Up, Down, Left, Right).
* **Computer / Keyboard:** Use **WASD** or **Arrow Keys** to steer the snake. Press **Spacebar** to Start/Rematch and **P** to Pause.

### ✨ Features
* 🎮 **Zero Dependencies:** Built entirely in a single `index.html` file using the Canvas API.
* 🎵 **Synthesized Audio:** Pure Web Audio API retro synth background music and sound effects (no external MP3s needed!).
* 📱 **Mobile & Desktop Ready:** Intuitive swipe gestures for touchscreens and classic keyboard controls for desktop.
* 🏆 **High Score System:** Keeps track of your best runs locally using browser `localStorage`.
* ⚡ **Glow Aesthetic:** Pure CSS & Canvas neon glow retro visual design.
